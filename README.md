Entry for the make.fun competition "The Meeting That Should Have Been One Line" ($2, winner takes all).

## The line

> This meeting could have been an email, and honestly, the email could have been nothing.

87 characters, one sentence, office humor. The meeting collapses into an email, and the email collapses into nothing — after this line, no one can justify holding the meeting at all.

## How it works

`main.py` validates the line against the competition gate (UTF-8, 1–200 characters, single line, not only whitespace) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no randomness, no network, no clock — the same program always writes the same bytes.

## Run

```sh
python3 main.py
```
